# AGENTS.md template

Copy this to the repository root as `AGENTS.md`, fill in the brackets, and delete every section that doesn't apply. Aim for under 150 lines. If a line wouldn't change what an agent does, cut it.

```markdown
# AGENTS.md

[Project name]: [one sentence on what it is and who uses it].

## Commands

- Setup: `[e.g. pnpm install]` (requires [Node 22 / Python 3.12 / Go 1.23], see `.tool-versions`)
- Test all: `[pnpm test]`
- Test one file: `[pnpm test -- src/foo.test.ts]`
- Test one case: `[pnpm test -- -t "name of test"]`
- Lint: `[pnpm lint]` (auto-fix: `[pnpm lint --fix]`)
- Typecheck: `[pnpm typecheck]`
- Build: `[pnpm build]`
- Run locally: `[pnpm dev]` -> [http://localhost:3000]

Before finishing any change, run: `[pnpm lint && pnpm typecheck && pnpm test]`

## Repository map

- `[src/api/]`: [HTTP handlers; thin, call into services]
- `[src/domain/]`: [business logic; pure functions, no I/O]
- `[src/db/migrations/]`: [generated by `pnpm db:migration`; never edit after merge]
- `[src/generated/]`: [generated by `pnpm codegen`; do not edit by hand]

## Conventions

- [Use `Result<T, E>` from `src/lib/result.ts` for expected errors; throw only for bugs.]
- [All money is integer cents (`amountCents`), never floats.]
- [Dates are UTC `Date` objects internally; format only in the UI layer.]
- [New endpoints need an integration test in `tests/api/`.]

## Gotchas

- [Tests share one Postgres; use the `withTransaction` helper or they interfere.]
- [The `legacy/` folder uses the old auth pattern; don't copy it.]

## Never

- [Commit secrets or `.env` files.]
- [Edit merged migrations; create a new one.]
- [Push to `main` or force-push shared branches.]
- [Delete files or data without asking first.]
```

## Pointing CLAUDE.md at it

To keep one source of truth, `CLAUDE.md` can contain a single import line:

```markdown
@AGENTS.md
```
